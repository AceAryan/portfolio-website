Conditional Access on FPGA

Extended the open-source CVA6 RISC-V core with hardware-level Conditional Access primitives — new instructions wired through decode, execute, and writeback. Single-core is done; currently working on multicore with inter-core CA enforcement and shared-memory access control. Advised by Prof. Ajay Singh at IITGN.

02

riscv-viz — Cycle-Accurate RISC-V Simulator

RV32I CPU simulator in C++17 with a custom assembly parser — no external assembler, byte-addressable little-endian memory. FastAPI backend exposes register and memory state per cycle; React + TypeScript frontend shows live register diffs and a hex dump. Containerised with Docker, deployed on Render. Live demo →

C++17 FastAPI React Docker Ongoing
03

TLS Fingerprinting — Passive Traffic Analyser

TLS handshake parser written from scratch in Python — reads raw ClientHello/ServerHello bytes, implements JA3, JA3S, and JA4 per the Salesforce and FoxIO specs. Handles fragmented packets via TCP stream reassembly. Identified 5 clients from the handshake alone, no decryption needed. Also showed that JA3 breaks when Chrome randomises extension order; JA4 doesn't. Advised by Prof. Sameer G Kulkarni.

Python Scapy Networking
04

Unix Shell

A Unix shell in C with built-ins (cd, pwd, echo, kill, exit) and arbitrary external commands. Uses fork/execvp/waitpid for process lifecycle and SIGQUIT for graceful termination. Built for the OS course with Prof. Balagopal Komarath.

C POSIX OS
05

StayEase — Distributed Database Engine

B+ Tree storage engine with a Write-Ahead Log for crash recovery. TransactionManager handles begin/commit/rollback with REDO/UNDO — tested under 100 concurrent threads, zero corruption. Data partitioned across 3 MySQL shards with hash-based routing and scatter-gather for cross-shard queries. Flask REST API with JWT auth and RBAC, load-tested at 100 concurrent users with 0% failure. Advised by Prof. Yogesh Kumar Meena.

Python MySQL Flask Distributed Systems
06

DataFlix — Recommender Systems Pipeline

Trained and compared 6 models (ALS, BPR, EASER, LightGCN, Two-Tower, Hybrid) on 32M ratings. EASER came out on top with NDCG@10 of 0.0891 — about 105% better than LightGCN. Built a Hybrid model combining collaborative filtering with SBERT embeddings for cold-start users; offloaded LightGCN graph ops to CPU to fit a 60M+ edge graph in 6GB VRAM. Advised by Prof. Anirban Dasgupta.
